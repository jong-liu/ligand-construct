ligand-construct — PubChem 配體庫建構器

依四階段 SOP 建立可追溯的小分子配體庫。本頁直接呼叫 PubChem PUG-REST，資料不經任何第三方伺服器。

GitHub repo 完整 SOP 文件 CLI 工具（批次用）

1目標化合物定位

輸入化合物名稱或 PubChem CID，核對分子式、分子量與 InChIKey 無誤後再往下。

2Tanimoto 相似度篩選

PubChem Fingerprint + Tanimoto 2D 相似度。網頁預設門檻 90%；要高特異性配體庫建議拉到 95%。

95%

3結構檔（SDF）導出

2D 座標供指紋比對；3D 座標供分子對接（每化合物 1 個 conformer，部分化合物無 3D 構型）。

4命名歸檔與可追溯性

檔名採 <母核>_like<門檻>.sdf，一眼看出來源與篩選條件，不會在多批次處理中混淆。

資料來源：NCBI PubChem（PUG-REST）。 大批次下載（數百筆以上）請改用 CLI：python tools/pubchem-fetch/pubchem_fetch.py --name paxlovid --threshold 95， 它會一併產出屬性表與 manifest。
